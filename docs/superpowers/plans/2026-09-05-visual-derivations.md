# 每一步推导的参数联动图解

目标：全部 11 个专题的每条推导都有相关图解，课堂逐步揭晓，基础自由交配补加权棋盘格；沿用现有遗传计算与公开发布。

实现：在 catalog.calculate 的结果中附加 typed diagrams，与 steps 一一对应；构建器复用计算报告的配子、指标、数据表。DiagramView 提供加权棋盘格、流向图、阶段柱图、DNA 新旧链、碱基配对及家系图。ReportView 与 GuidedReport 共用单步呈现。

验证：先写缺失行为测试；覆盖11专题和所有预设、图文逐步显示、连锁 r=0/20/50、致死全空与部分致死、ABO和伴性概率、DNA第0轮及30轮、细胞分裂、自交0代、概率边界；检查原有全量测试和构建，独立审查后发布。
