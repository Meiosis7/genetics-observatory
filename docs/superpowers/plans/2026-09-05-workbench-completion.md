# 高中专题工作台完善 Implementation Plan

**Goal:** 延续已有风格和全部模型，完成专题查找、参数保留、实验存档及课堂分步推导。
**Architecture:** 保留现有纯函数计算引擎。在 AdvancedPage 管理会话参数，在独立 notebook 模块管理经过验证的本机存档，在独立教学组件管理答案揭晓。
**Tech Stack:** React、TypeScript、Vitest、现有 CSS tokens。

## Constraints
- 所有计算本地执行，不上传输入；维持 11 个专题模型边界。
- 无效输入隐藏结果；存储失败明确提示；不修改现有基础实验记录。
- 保留现有 GitHub Pages 公开发布方式。
