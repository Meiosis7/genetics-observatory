# 连续动画教师推导

用户要求：教师推理每一步之间割裂，改成动画形式。

实现：基础和专题教师模式共用固定演播台。MotionStage 在更新 DOM 前记录语义元素位置，更新后通过原生 Web Animations 从旧位置移动到新位置，并高亮内容变化；保留最近过渡起点供本步重播。配子、组合、图表系列有独立身份。无支持或减少动态效果时静态显示。

控制：自动推进、暂停自动推进、3/5/8秒节奏、上一步、重新开始及本步重播；参数改变时专题组件重挂载并清除计时器。未来步骤不提前显示，正常模式仍保留完整逐步图文。

验证：新增行为测试覆盖同一演播台、前后步、暂停、输入重置、基本演示结论、Escape控件聚焦；动画测试验证实际坐标差和重播同一路径、减少动态效果；多系列动画身份测试。独立审查发现的Escape过滤顺序及系列ID问题均以回归测试复现并修复。
