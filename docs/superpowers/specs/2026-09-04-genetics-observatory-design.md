# 遗传观察所：首版产品设计

## 1. 产品目标

构建一个面向中学生与教师的中文遗传学交互平台。学生能够独立完成遗传杂交计算并理解推导过程，教师能够在课堂上快速设置案例、逐步揭晓结果并进行大屏演示。

首版无需注册，打开即可使用，实验历史保存在浏览器本地。平台优先保证基础孟德尔遗传计算准确、操作清晰和教学表达完整，再在后续版本扩展伴性遗传、连锁交换与多基因复杂条件。

## 2. 首版范围

### 2.1 支持的遗传计算

- 单基因与双基因杂交。
- 普通杂交、自交、测交、回交与自由交配。
- 完全显性遗传，使用大写字母表示显性等位基因、小写字母表示隐性等位基因。
- 自动生成亲本配子及其概率。
- 自动生成潘尼特方格，并统计子代基因型、表现型及概率。
- 概率同时展示为分数、百分比和比例。
- 提供豌豆颜色、豌豆形状等可直接载入的经典案例。

### 2.2 暂不纳入首版

- 伴性遗传、复等位基因、不完全显性、共显性。
- 连锁遗传、交换率与遗传图谱。
- 三对及以上等位基因的组合计算。
- 云端账号、班级管理、跨设备同步与多人协作。

这些能力作为后续高级模块加入，不影响首版计算核心的扩展接口。

## 3. 信息架构

### 3.1 首页

- 品牌介绍与“开始一次实验”主按钮。
- 普通杂交、自交、测交、回交、自由交配五类实验入口。
- 单基因与双基因经典案例。
- 最近实验记录。
- 学生模式与教师演示模式切换入口。

### 3.2 混合实验台

采用已确认的“左侧设置、右侧实时推导”布局。

左侧设置区包含：

- 实验类型。
- 单基因或双基因模式。
- 性状名称、基因符号和显隐性描述。
- 双亲基因型。
- 随设置即时更新的有效性提示。
- 重置、交换亲本、播放推导按钮。

右侧推导区包含：

- 亲本概览。
- 配子及概率。
- 潘尼特方格。
- 基因型分布。
- 表现型分布。
- 可复制的文字结论。

### 3.3 教师演示模式

- 可全屏展示，隐藏非必要导航与编辑控件。
- 通过“上一步 / 下一步”逐步揭晓亲本、配子、组合与结论。
- 默认使用更大的字号和更高的色彩对比度。
- 支持直接返回编辑实验。

### 3.4 实验记录

- 成功计算后自动保存实验摘要到浏览器本地。
- 可重新载入、复制或删除单条记录。
- 设置最大保存数量，超过后自动移除最早记录。
- 清空全部记录需要二次确认。

## 4. 视觉设计

使用已确认的“科学杂志编辑风”。

- 主色：植物深绿，负责导航、标题与高权重信息。
- 强调色：珊瑚红，负责主要操作和关键结果。
- 辅助色：芥末金与鼠尾草绿，用于基因组合、概率图与状态编码。
- 背景：暖米白纸张质感，卡片保持高可读性。
- 排版：中文无衬线字体用于界面，具有编辑感的标题层级强化“实验手册”气质。
- 形状：适度圆角、细描边、轻微错位投影，不使用通用企业后台式组件外观。
- 动效：配子从亲本卡片流向潘尼特方格，结果分布按顺序出现；所有动效支持减少动态效果的系统设置。

## 5. 交互与数据流

用户修改亲本或实验条件后，输入首先经过语法和遗传规则校验。合法输入转换为统一的遗传实验模型，计算引擎枚举亲本配子、组合子代、合并等价基因型并计算概率。界面通过同一个结果对象渲染方格、比例图与文字结论，避免多个视图产生不一致结果。

计算过程完全在浏览器内完成，不上传学生数据。实验记录只保存必要的设置、结果摘要与时间戳。

## 6. 错误处理

- 非法基因型在输入位置就近解释，例如“同一基因位点必须包含两个等位基因”。
- 不允许开始不完整实验，但保留用户已经输入的内容。
- 本地存储不可用时仍可正常计算，只显示一次非阻塞提示。
- 无有效结果时不展示空图表，改为显示可执行的修正建议。
- 未知运行错误显示友好的恢复入口，并保留当前实验设置。

## 7. 技术方案

- 使用 React、TypeScript 与 Vite 构建单页应用。
- 计算核心采用无界面的纯函数模块，与页面组件解耦。
- 浏览器本地存储保存实验记录和模式偏好。
- 使用 CSS 变量和独立设计组件实现统一主题。
- 首版为纯前端静态站点，可部署至常见静态托管服务。

## 8. 测试与验收

- 为配子生成、组合概率、基因型规范化与表现型聚合编写单元测试。
- 用 Aa × Aa、AaBb × AaBb、测交和回交等经典结果作为固定用例。
- 验证所有概率总和严格等于 1，并验证分数约分和比例化简。
- 验证页面在桌面、平板和手机宽度下可操作。
- 检查键盘导航、颜色对比度、焦点状态与减少动态效果设置。
- 教师演示模式在 16:9 投屏比例下无需滚动即可展示当前步骤。

## 9. 首版完成标准

用户能够从首页选择实验或案例，设置一至两个基因位点的亲本，得到准确的配子、潘尼特方格、基因型、表现型和文字结论；能够逐步播放推导、切换教师演示模式，并在无需账号的情况下重新打开本地历史实验。整体界面符合“科学杂志编辑风”，不沿用参考视频的浅色通用后台外观。
