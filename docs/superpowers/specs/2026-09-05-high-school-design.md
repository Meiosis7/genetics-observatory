# 高中遗传工具集

用户授权：按推荐方案直接交付，不再进行方案选择。延续已确认的科学杂志风和本地计算，不上传学习数据。

## 产品结构

保留基础杂交实验台与历史记录。首页和顶栏增加「高中专题」，进入左右分栏工具台，左侧切换主题并设置参数，右侧即时显示概率、推导、条件与误区。默认打开致死专题。

常用工具：配子/合子致死（分别列雌雄配子存活率、受精后合子存活率、归一化分布）；X 隐性/X 显性/Y 连锁遗传；ABO 血型；核心家庭系谱候选模型排除；连续自交与显性个体筛选；群体基因频率与平衡；DNA 碱基/氢键/半保留复制；有丝及减数分裂数量；独立出生事件概率。

拓展工具：双位点连锁交换（分别设相位和重组率）；不完全显性/共显性与双基因互作特殊比例。明确拓展标签，不声称所有地区考试必考。

## 计算约束

- 全部纯函数，本地运行；百分比显示四舍五入，内部保留数值精度。
- 配子致死作用于雌、雄各自配子池，存活后各自归一化。不得把两配子池存活率乘积标成真实生育率。全部配子死亡时无后代分布。
- 合子致死以受精后合子为分母，支持按位点指定基因型和 0–100% 外显致死率；双位点规则独立作用。
- 伴性遗传明确全部子代与性别条件概率；系谱只提供可行模型，不从信息不足的家庭推断唯一遗传方式。
- DNA 工具限定双链 DNA；复制最多 30 轮。细胞分裂以单个细胞计数并解释后期染色体计数。
- 参数无效时隐藏旧结果、展示中文错误；不存在的条件分母显示无定义，而非 0%。
- 所有工具提供样例重置、复制结果、打印；已有基础记录保持兼容。
- 不做真实遗传病诊断、全家系概率诊断或任意生物过程模拟。

## 验证

标准例：Aa×Aa 且 AA 致死 → 合子存活 3/4，存活 Aa:aa=2:1；雄 a 配子致死 → AA:Aa=1:1；连锁 AB/ab r=.2 测交 → .4,.1,.1,.4；伴 X 隐性携带母亲×正常父亲 → 全部子代患病 1/4、儿子中 1/2；ABO AO×BO → 四血型各 1/4；Aa 自交 n 代杂合率 2^-n；双链 DNA 半保留复制 n 轮含原链分子比例 2/2^n（n≥1）。测试覆盖零分母、极值、无效参数及界面切换。
