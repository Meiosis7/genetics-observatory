# 遗传观察所

[![Tests](https://img.shields.io/badge/tests-92%20passing-17382d)](https://github.com/Meiosis7/genetics-observatory/actions)
[![License: MIT](https://img.shields.io/badge/license-MIT-e76f51.svg)](LICENSE)

在线体验：[GitHub Pages](https://meiosis7.github.io/genetics-observatory/)

一个面向高中学生与教师的遗传学交互平台。所有计算在浏览器中完成，不上传学习输入。延续纸张、森林绿与珊瑚色的科学杂志界面。

## 探索式学习

首页以“亲本与子代、特殊遗传、群体变化、DNA 与细胞”四条路径组织 11 个研究问题，支持搜索并直达对应实验。顶部的单基因杂交小实验可切换亲本、观察组合、揭晓比例，计算由正式遗传引擎驱动。

专题实验支持“设为对照”：固定一组条件，再改变参数，并排查看对照与当前指标。课堂推导模式隐藏对照和完整结果，避免提前显示答案。

## 已实现

- 单基因与双基因杂交
- 普通杂交、自交、测交、回交
- 基于 Hardy–Weinberg 平衡的自由交配计算
- 配子生成、潘尼特方格、基因型与表现型统计
- 可编辑的性状名称和显隐性表现
- 五步教师演示模式
- 本机实验记录
- 桌面、平板和手机响应式界面

## 高中专题工具箱

从顶栏「高中专题」或首页入口打开，共 11 个专题，均支持参数修改、即时结果、推导笔记、条件说明、重置、复制和打印/PDF。

- 专题搜索：按主题、题型和介绍查找，手机端支持横向切换。
- 条件保留：在专题工具箱内切换专题，保留本次打开期间各题的输入；离开工具箱前可保存题目。
- 本机实验本：给题目命名并保存，重新打开浏览器后可恢复或删除，最多保留最近 30 条；保存失败会明确提示。
- 课堂推导：先隐藏答案，逐步揭晓推导，最后显示完整结果；修改条件后自动从头开始。退出课堂推导后可复制或打印完整报告。

| 专题 | 支持内容 |
| --- | --- |
| 致死与存活筛选 | 单/双基因，雌雄分别指定致死配子，按位点设置合子致死与部分致死率；致死前后比例、存活率、全死边界 |
| 伴性遗传 | X 隐性、X 显性、Y 连锁，总体及性别条件概率 |
| ABO 血型 | 六种亲本基因型与后代血型分布 |
| 系谱模型排除 | 一个核心家庭对 AR/AD/XR/XD/Y 五种模型的可行性筛选 |
| 连续自交 | 从 Aa 出发，0–20 代，不筛选或每代去除 aa |
| 群体遗传 | 从基因型计数求等位基因频率，对照 Hardy–Weinberg 理论 |
| DNA | 双链碱基、氢键、0–30 轮半保留复制、新核苷酸数 |
| 细胞分裂 | 单细胞的有丝/减数分裂阶段数量表 |
| 子代事件概率 | 二项分布，恰好 k 次、至少一次及零次 |
| 连锁与交换（拓展） | 雌雄相位与 0–50% 重组率，权重计算 |
| 显性关系与互作（拓展） | 不完全显性、共显性、9:7、15:1、9:3:4、12:3:1、13:3、9:6:1 |

### 每步图解推导

全部 11 个专题的每条推导都配有与输入联动的图解，课堂模式同步逐步揭晓。基础自由交配也提供加权棋盘格。

- 致死：原始配子、配子筛选、受精棋盘格、合子存活权重、存活贡献与归一化图。
- 伴性、ABO、连锁、互作：按真实配子概率绘制棋盘格，并展示性别条件概率或表现型归类。
- 系谱：核心家庭图、模型检验和排除结果。
- 自交、群体：逐代变化曲线、等位基因计数流向与随机结合棋盘格。
- DNA：互补配对、氢键及半保留复制的新旧链来源；大轮次数值标注，不展开海量分子。
- 细胞分裂：各阶段染色体形态示意与单细胞精确计数；超过 8 条时明确标注示意限制。
- 事件概率：事件分支、位置排列与对立事件图。

图解支持手机横向查看和打印，颜色之外也以文字区分致死、新旧链与各类结果。

### 模型边界

这些是高中常见题型的明确模型，不宣称穷尽所有教材与高考题。基础实验默认一/两个常染色体位点、完全显性与独立分配。不同专题条件不能自动叠加（例如当前伴性模型不叠加致死）。系谱是核心家庭模型排除，不是多代家系编辑器或诊断工具。专题使用独立的本机实验本，不混入基础实验历史，也可复制或打印保留。清除浏览器网站数据会清除本机记录。

配子存活率分别以雌雄原始配子池为分母，筛选后各自归一化；两配子池存活率乘积不代表生育率。合子存活率以已受精合子为分母。全部死亡时不生成虚假的存活比例。

参考：[高中课程标准发布通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)、[OpenStax 遗传规律](https://openstax.org/books/biology-2e/pages/12-2-characteristics-and-traits)、[连锁与交换](https://openstax.org/books/biology-2e/pages/13-1-chromosomal-theory-and-genetic-linkage)。仅用于学习，不作医学或亲子鉴定判断。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端中显示的本地地址。

## 验证与构建

```bash
npm test -- --run
npm run build
```

生产文件输出到 `dist/`，可部署至任意静态网站托管服务。
