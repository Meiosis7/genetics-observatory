# 遗传观察所

一个面向中学生和教师的孟德尔遗传可视化实验平台。无需注册，所有计算都在浏览器中完成。

## 已实现

- 单基因与双基因杂交
- 普通杂交、自交、测交、回交
- 基于 Hardy–Weinberg 平衡的自由交配计算
- 配子生成、潘尼特方格、基因型与表现型统计
- 可编辑的性状名称和显隐性表现
- 五步教师演示模式
- 本机实验记录
- 桌面、平板和手机响应式界面

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端中显示的本地地址。

## 验证与构建

```bash
npm test -- --run
npm run build
```

生产文件输出到 `dist/`，可部署至任意静态网站托管服务。
